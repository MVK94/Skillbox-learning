List comprehension - Генерация списка
squares = [x ** 2 for x in range (10)]

x ** 2 - expression(выражение)
for x in - member (переменная цикла)
range (10) - iterable (функция, срока, список ...любой итеррируемый объект)

ПРИМЕР

double = [x * 2 for x in 'abc']  =  ['aa', 'bb', 'cc']

Так же можно использовать условную логику (conditional)

 squares_odds = [x ** 2 for x in range (10) if x % 2 != 0]

 если нужно отфильтровать элементы из итеррируемого объекта и создать из них список, то логика пишется в конце.


 Например, надо возвести в степень 3 каждое нечетное число, а четное в квадрат

 squares_cubes = [(x ** 2 if x % 2 != 0 else x ** 3) for x in range (10)]
